## Overview

**Nexus One** is a production-ready, single-file enterprise operating system that replaces the entire stack of CFO, HR, and operational software with a single AI-powered platform. Built by Realtouch Global Ventures Ltd, it serves UK companies of all types and sizes — from startups and sole traders to charities, CICs, healthcare providers, and multi-entity enterprises.

Unlike SAP, Oracle, or Workday — which cost £100–£800 per user per month and require 6–18 month implementations — Nexus One delivers the same depth of functionality, backed by live Claude AI intelligence, accessible to any organisation from day one.

## Core Capabilities

### AI CFO
- **General Ledger** — Full double-entry chart of accounts with journal posting
- **Accounts Receivable** — Invoice generation, customer register, aged debtors (4 buckets), credit control chase schedule
- **Accounts Payable** — Supplier invoice approval workflow (Pending → Approved → Paid), 3-way PO matching, payment batch runs
- **VAT & Making Tax Digital** — Box 1/4/5 VAT return calculator from live AR/AP, MTD submission (HMRC API-ready)
- **Budgets & FP&A** — Budget vs Actual tracking, departmental analysis, full-year forecast, AI-generated variance narratives
- **Cash Flow Forecast** — 13-week rolling forecast from live payroll + invoices, 3-scenario modelling (Optimistic / Base / Stress), Runway Calculator
- **Financial Reports** — FRS 102 P&L, Balance Sheet, Cash Flow Statement, SORP-compliant SoFA, AI-generated Management Accounts, AI Board Pack
- **Donations & Gift Aid** — Donor register, Gift Aid tracking (25% HMRC reclaim calculation), 6-month trend chart
- **Grant Management** — Multi-funder grant register, utilisation tracking, pipeline, AI grant report generation

### AI HR Director
- **HMRC Payroll Engine** — PAYE (tax bands), Employee NI (8%), Employer NI (13.8%), Pension AE (NEST 3%+5%), NMW validation gate (£11.44/hr), tax code management
- **RTI Compliance** — FPS/EPS submission tracking with HMRC Government Gateway integration (live API-ready), P60, P45, P11D, P11D(b) generation
- **Right to Work** — List A/B register, BRP-to-eVisa transition deadline tracking (Dec 2026), £45k/£60k penalty awareness, automated recheck alerts
- **DBS & Safeguarding** — Enhanced DBS + Barred List register, safeguarding training log, DBS Update Service tracking
- **Leave Management** — Annual/Sick/Maternity/Paternity/Compassionate leave, SSP (£116.75/wk), SMP (£184.03/wk), SPP, Bradford Factor absence scoring
- **ACAS Disciplinary** — Disciplinary/grievance case management compliant with ACAS Code of Practice, PIDA whistleblowing log
- **HR Records** — Employee register, onboarding workflows, contracts library, org chart, headcount analysis
- **Training & CPD** — Training register, mandatory training tracker, certification expiry alerts
- **Equality Act 2010** — All 9 protected characteristics monitoring, anonymised workforce profile, gender pay gap tracking
- **Rota & Timesheets** — Weekly rota builder, Working Time Regulations 1998 compliance (48-hour rule)

### UKVI & Sponsorship (Best-in-Class)
- **Sponsor Licence Management** — 3-tier key personnel structure (AO/L1/L2), A/B rating, compliance score
- **Sponsored Worker Register** — £38,700 going rate check, visa expiry tracking, salary breach alerts
- **Certificate of Sponsorship** — CoS register, allocation tracking (10 CoS pool)
- **All 10 Reporting Duties** — 10-working-day and 20-working-day rules, absence monitoring, BRP-to-eVisa deadline
- **Home Office Audit Pack** — Appendix D checklist, 48-hour visit readiness scoring, one-click pack generation

### AI Intelligence Layer
- **Live Claude Sonnet API** — Not a chatbot add-on. The AI builds a dynamic system prompt from your organisation's live financial position, payroll, grant status, compliance gaps, and personnel — every single query
- **Contextual alerts** — "Your NLCF interim report is due in 13 days and you are 85% of budget utilised"
- **Document generation** — Grant reports, trustee summaries, board packs, compliance summaries, employment contracts, management accounts — all from real data
- **FP&A narratives** — AI-generated variance analysis, cash flow recommendations, runway advice
- **Persistent chat history** — Conversation context maintained across sessions

### Compliance & Governance
- **GDPR/DPA 2018** — ICO registration tracking, DSAR workflow (30-day deadline), Article 30 ROPA, data retention register
- **Compliance Hub** — Live scoring across 14 compliance dimensions, deadline calendar, AI-generated action items
- **Governance** — Trustee/Director register, conflict of interest log, CIC community interest statement
- **Security Centre** — 2FA (TOTP + SMS), active session management, encryption status audit, ISO 27001 gap analysis, compliance certification roadmap
- **Immutable Audit Log** — Every action logged with timestamp, user, module, detail, and IP

## Security Notice

> ⚠️ **Phase 1 Prototype Notice**
>
> This is a production-quality frontend prototype. The current implementation uses `localStorage` for data persistence. For production deployment with real client data, the following must be implemented:
>
> - AES-256-GCM field-level encryption (NI numbers, bank details, passport numbers)
> - JWT with Redis blacklist and refresh token rotation
> - PostgreSQL with row-level security (schema per tenant)
> - TLS 1.3 on all API traffic
> - 2FA enforcement (TOTP) for all users
> - SOC 2 Type I readiness assessment
>
> See the [PRD](./docs/PRD.md) for the full production architecture specification.

**The Anthropic API key is NOT stored in this codebase.** In production, all Claude API calls route through a backend proxy that injects the key server-side.

## Quick Start

### Option 1: Browser (Prototype — no setup required)
```bash
open nexus-one.html
```

### Option 2: Full Stack (Production backend)
```bash
# Copy and configure environment
cp .env.example .env
# Edit .env — add your ANTHROPIC_API_KEY and database credentials

# Start all services
docker-compose up -d

# Run database migrations
make migrate

# Seed demo data
make seed

# Access the app
open http://localhost:3000
```

### Option 3: Backend only
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
# API docs: http://localhost:8000/docs
```

### Environment Variables
See `.env.example` for all required variables. Key ones:
```bash
ANTHROPIC_API_KEY=sk-ant-...       # Required for AI features
DATABASE_URL=postgresql://...       # PostgreSQL connection
REDIS_URL=redis://localhost:6379    # Redis for sessions/queue
SECRET_KEY=...                      # JWT signing key (generate with: openssl rand -hex 32)
```
